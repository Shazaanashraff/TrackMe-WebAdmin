All three render the same screen — the super-admin Dashboard — so they're comparable. Every number is illustrative, but the behaviour is honest: where a real series doesn't exist, each design shows its own version of an empty state rather than a fake curve. Fonts are approximated with system stacks (the artifact sandbox blocks font CDNs); the intended faces are named on each tab.

The safe, professional one — and what's already committed in code. Linear/Stripe register: calm slate ground, one emerald accent, generous page-level whitespace with efficient density inside tables. Best when the job is "operators scan it all day and never think about it."

Committed to a single dark world — a control room isn't a light-mode surface. A light counterpart would be designed only if operators ask for one.

The unusual one — and the argument is that a bus company already has a design language. Timetables, departure boards, route diagrams, Swiss transit signage. So the interface stops pretending to be a SaaS dashboard: no cards, no boxes, no shadows, no widgets. Navigation is a route line and the pages are its stops. The KPIs are a printed masthead, the approval queue is a departure board, and the only colour in the entire screen is one transit red — spent exclusively on "this needs a human."
